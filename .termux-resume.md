### Se o Termux fechar, como retomar
- O código está em `/root/pulsa` e **sobrevive**: reabrir o Termux e `cd /root/pulsa`.
- Só o que está em `/tmp/opencode/` se perde (é tmpfs, limpa no reboot): logs, APKs de backup e
  snapshots do `res/`. A baseline do gate foi por isso movida para dentro do repo, em
  `scripts/baseline/`. Não dependa de `/tmp` para nada que precise durar.
- Build/teste em andamento morre junto com o app — só retomar rodando de novo.
- Antes de qualquer coisa em XML: rodar o gate, porque ids de recurso mudam a cada token novo.
  ```bash
  ./gradlew :app:assembleDebug --console=plain          # ~14min nesta máquina
  ./scripts/verificar-visual.sh gate app/build/outputs/apk/debug/app-debug.apk scripts/baseline/t02-aurora
  ./gradlew :app:test --console=plain                   # 88 execuções
  ```

## Ensinamentos da sessão (novos)
- Corrigir tag de abertura E fechamento quando trocar `CardView` → `MaterialCardView` (AAPT exige).
- Hex com dígito a mais (ex.: `#1FFFF2E4D`) → AAPT "incompatible with attribute color".
- `RadarPanelDrawable` precisa do `inflate(Resources, XmlPullParser, AttributeSet)` (3-arg, API 23)
  além do 4-arg (API 24+) e do import de `com.pulsa.player.R`.
- Style Android sem `parent` com nome `Widget.Pulsa.X` herda de `Widget.Pulsa` (inexistente) → AAPT
  "resource style/Widget.Pulsa not found". Sempre dar `parent` válido.
- Nesta máquina o `compileDebugKotlin` é o gargalo (pode passar de 10 min) — não interromper o gradle.
- Layout XML usando `app:shapeAppearance` precisa de `xmlns:app` no raiz (senão "prefix unbound").
- `android:scrollX`/`scrollY` em XML exigem unidade (`0dp`, não `0`).
- Extension e função com mesmo nome+sigla (ex.: `Int.dp()` e `dp(Int)`) colidem no JVM — usar um só.
- Se recurso "não existe" no código do usuário (`np_ab_*`, `ab_needs_a`), procurar no repo antes de
  criar: `ab_needs_a`/`ab_clear` já existiam em pt (default), só faltavam em en/es.
- `pm install` no MIUI falha mesmo como root/shell (XSpace exige MANAGE_USERS/CREATE_USERS) e o
  `am` precisa de uid shell com permissão de pacote — instalar sempre via UpdateChecker do app.
- Em strings-en, apóstofro DEVE ser escapado (`\'`) — sem escape, aapt2 do AGP dá
  "Invalid unicode escape sequence in string".- `aapt2 dump xmltree` aceita VÁRIOS `--file` numa só invocação: 146 recursos em 9s, contra
  ~8min chamando um por vez. O `--values` do aapt2 do SDK não resolve referência de recurso
  (imprime `@0x7f0a00a2`), então o valor da cor tem de vir do `aapt2` empacotado pelo AGP em
  `build/intermediates/aapt2*/`; sem resolver, o gate acusa 1068 linhas de "regressão" que são
  só mudança de representação do id.
- Nunca editar um script shell enquanto ele roda: o Bash lê o arquivo incrementalmente e o que
  estiver escrito no meio passa a ser executado como comando. Escrever o arquivo inteiro de uma vez
  ou esperar terminar.
- `@color` NÃO sobrevive à geração de PNG em build (o pipeline do AGP converte para bitmap e
  fica sem o recurso). Os 4 drawables legados ficam com hex literal.
- Commit de duas fases num estado só: reconstruir o estado intermediário, commitar, restaurar o
  final e conferir o hash (`md5sum` dos arquivos ordenados) antes de commitar — o hash é o que
  garante que o "final" voltou igual ao que estava verificado.
- O CI roda em push para `main` e **sempre republica** `pulsaweb/Pulsa.apk`, a menos que
  `REMOTE_CODE >= CODE`; por isso commit sem bump de `versionCode` é publicação inócua, e é assim
  que se manda trabalho não-released sem Arriscar o APK em produção.
